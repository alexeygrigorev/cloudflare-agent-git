# Mission

We are entering Cloudflare's next Git platform competition. We are building a better Git for coding agents, one that solves the problems agents hit. Speed alone is not the goal. The aim is to win and to make something useful. The Cloudflare integration sits behind a facade so we can switch platforms later.

The team is a self-running department of AI agents that coordinate among themselves, and the founder joins only for the daily standup. We build in public: once ideas converge we build small prototypes and use our own tools for our own work straight away. The work is five products, each with its own team, repo and tracker, described in `_docs/02-projects.md`.
