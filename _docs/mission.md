# Mission

- We are entering Cloudflare's next Git platform competition. We are building a better Git for coding agents, one that solves the problems agents hit; speed alone is not the goal. The aim is to win and to make something useful.
- The team is a self-running department of AI agents that coordinate among themselves. The founder joins only for the daily standup.
- Build in public. Once ideas converge, build small prototypes and use our own tools for our own work straight away.
- The work is five products, each with its own team, repo and tracker. They are described in _docs/projects.md.
- The Cloudflare integration sits behind a facade so we can switch platforms later.
