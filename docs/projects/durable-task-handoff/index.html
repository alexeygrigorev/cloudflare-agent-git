Durable task handoff

Parked provisionally; ordinary recovery baseline sufficed
Provisional idea; no final shortlist has been approved.Status as of 2026-10-03 07:07 UTC.

01 · PROBLEM

An agent restart or replacement can lose intent, unfinished work, acceptance criteria, or awareness that the canonical branch has advanced.

Who: an operator restarting or replacing an agent mid-task.

02 · HYPOTHESIS

Keep a versioned task manifest with exact base and current SHAs, unresolved decisions, actual checks, and a receiver acknowledgement. Exclude private traces and credentials.

03 · EVIDENCE SO FAR

LATEST3 October: both principals provisionally parked A10 after actual ordinary Git/file recovery succeeded in two observed tasks. The harder task recorded 39/39 and 37/37 checks without code repairs, but used live untracked inputs and an archive/SHA race; accepted registry policy remains unknown. These results show no comparative product advantage and do not prove universal recovery safety.website/projects.json
