01 · PROBLEM

Alexey’s linked worktrees grew quickly on disk. A scan of one host found 111.7 GiB across 472 worktrees, with dependencies and builds accounting for 62.1% of the physical union.

Who: Alexey, and operators constrained by local disk.

02 · HYPOTHESIS

Account for source, immutable dependencies, mutable outputs, caches, and logs separately. Compare ordinary package sharing, sparse or copy-on-write worktrees, and remote execution without hiding allocation costs.
