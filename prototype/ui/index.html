What the labels mean
  • ✕Conflict Tested together, the two changes clash. Someone needs to look.
  • ✓Clean — tests ran Both latest changes were combined, the combined tests ran, and nothing clashed.
  • ?Unknown — not safe The radar checked the pair but could not prove it safe. Do not rely on it.
  • –Not checked Not compared at the latest changes yet, or compared without running combined tests. Not safe.

Each agent’s own passing tests never make a pair safe: two changes that pass alone can still break each other.
