What the labels mean

  • Conflict The agents’ changes clash. Someone needs to look.
  • Clean — tests ran No clash found, and both agents ran their tests at these changes.
  • Unknown — not safe Not proven safe. There is no passing test run for the latest changes, so do not rely on this pair.
  • Not checked These changes have not been compared yet.
