## Independent primary-source checks

**Semantic negative evidence (E-X020).** Opened [Passes Alone, Fails Together](https://arxiv.org/html/2609.25396v1), September21 preprint. It reports one interference case in834 runs on417 mined Django PR pairs after fixing unequal tests and agent-edited test contamination. Constructed real-helper tasks report105/108 failures and89/108 recoveries with a completed-change oracle message. These constructed rates do not estimate real incidence; oracle messages do not test live WIP communication. This weakens broad prevalence claims and makes same-suite base/A/B/combined validation mandatory. New local interaction-fixture.py passes base/A/B, clean-merges, then fails combined under the same oracle; scripts, not agents. Earlier greeting illustration did not use equal suites.

**Existing lazy-workspace capability (E-X021).** Opened [Cloudflare ArtifactFS guide](https://developers.cloudflare.com/artifacts/guides/artifact-fs/) and fetched [official README at2b87a486](https://github.com/cloudflare/artifact-fs/blob/2b87a48691ef4ae82d391b7bbe4976c06c7fadf7/README.md). They describe FUSE mounting/on-demand hydration; the README also describes writable overlay, required-commit verification and fallback to eager selected-revision blobs when the server lacks filtering. This is documented behavior, not locally tested durability or capacity. A lazy Git filesystem alone is already an incumbent; compare bounded whole-environment storage and recovery instead.

**Protocol qualification.** Our earlier blanket “Artifacts cannot partial-clone” was too broad: the [Git protocol page](https://developers.cloudflare.com/artifacts/api/git-protocol/) lists missing `filter` among optional **v1** capabilities and separately supports v2 fetch. The ArtifactFS guide describes blobless hydration on Artifacts. README warns of eager fallback without advertised filter support. We have not tested Artifacts v2 capability negotiation, lazy transfer or retained bytes. Correct statement: v1 filtering documented unsupported; actual v2/ArtifactFS behavior unresolved, never budget blobless savings without measurement. This is not proof filtering works, nor proof all local lazy approaches fail.

**Collide lead remains uncertain here.** Direct homepage retrieval failed in this tool. Pro4 supplies broader vendor-described claims while Pro1 could not verify them; no unverified capability absence or superiority adopted. Existing Forge/Weave/Switchman/CASP/Pact/Worktrunk sources in the Pro reports merit current primary-source checks before novelty sign-off.
